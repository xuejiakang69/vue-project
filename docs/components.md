# 公共组件文档

> 本文档记录所有公共组件的使用方式。每次新增或修改公共组件时，必须同步更新本文档。

## 一、布局组件

### 1.1 AdminLayout

**位置**: `src/layouts/AdminLayout.vue`

**说明**: 管理端主布局容器，包含侧边栏、顶部导航和内容区域。

**使用方式**:

```vue
<template>
  <AdminLayout>
    <router-view />
  </AdminLayout>
</template>
```

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| - | - | - | 无 Props，直接包裹内容 |

---

### 1.2 Sidebar

**位置**: `src/layouts/components/Sidebar.vue`

**说明**: 左侧菜单组件，支持折叠。

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `collapsed` | boolean | `false` | 是否折叠 |

**Events**:

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `toggle` | - | 点击折叠/展开按钮时触发 |

---

### 1.3 Header

**位置**: `src/layouts/components/Header.vue`

**说明**: 顶部导航栏，显示系统标题、用户信息和退出按钮。

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `username` | string | `''` | 当前用户名 |

**Events**:

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `logout` | - | 点击退出按钮时触发 |

---

### 1.4 Breadcrumb

**位置**: `src/layouts/components/Breadcrumb.vue`

**说明**: 面包屑导航，根据当前路由自动生成。

**使用方式**:

```vue
<Breadcrumb />
```

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| - | - | - | 自动根据路由生成，无需传参 |
